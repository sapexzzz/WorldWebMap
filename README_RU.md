# World Web Map

World Web Map — мод для Minecraft 1.20.1, создающий веб-карту уже исследованной местности.

Ветка `main` содержит только документацию и служит точкой входа в репозиторий. Она не предназначена для сборки или выпуска.

## Активная разработка

- [Fabric 2.2](../../tree/2.2fabric) — версия `0.2.2`, ещё не выпущена.
- [Forge 2.2](../../tree/2.2forge) — версия `0.2.2`, ещё не выпущена.

Ветки `2.1fabric` и `2.1forge` сохранены как неизменяемая архивная история. Правила веток описаны в [docs/BRANCHES.md](docs/BRANCHES.md).
