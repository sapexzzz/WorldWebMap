# World Web Map

World Web Map is a Minecraft 1.20.1 mod that renders a web-accessible map of explored terrain.

`main` is the repository landing page and contains documentation only. It is not a build or release branch.

## Active development

- [Fabric 2.2 development line](../../tree/2.2fabric) — version `0.2.2` release candidate, not yet published.
- [Forge 2.2 development line](../../tree/2.2forge) — version `0.2.2` release candidate, not yet published.

The `2.1fabric` and `2.1forge` branches are archived frozen history. No release, tag, or release artifact is created by this documentation branch.
