# Mentalitys | World Web Map

> [Русская версия](README_RU.md)

World Web Map is a server-side Minecraft **1.20.1** web map for **Fabric** and **Forge**. It serves an interactive browser-based map of explored terrain; players need only a browser, with no client mod required.

## Current release

### Published

The current published release is **0.2.1** for both loaders: [Fabric 0.2.1](https://github.com/sqwiziiy/World-Web-Map/releases/tag/2.1fabric) and [Forge 0.2.1](https://github.com/sqwiziiy/World-Web-Map/releases/tag/2.1forge).

### Current development

Version **0.2.2** is a release candidate and is **not published yet**. Its source is maintained on [`2.2fabric`](https://github.com/sqwiziiy/World-Web-Map/tree/2.2fabric) and [`2.2forge`](https://github.com/sqwiziiy/World-Web-Map/tree/2.2forge).

## Branches

`main` contains project information only; it is not a source or build branch. The actual source lives on `2.2fabric` and `2.2forge`; `2.1fabric` and `2.1forge` are archived historical snapshots. Choose the JAR for your loader: a Fabric JAR is not a Forge JAR, and vice versa.

The project implementation uses Java, with JavaScript, CSS, and HTML for the browser map interface.
